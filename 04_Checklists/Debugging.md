# Чек-лист отладки

1. Прочитай первую ошибку в Console, а не последнюю.
2. Воспроизведи проблему стабильно.
3. Сформулируй гипотезу.
4. Проверь её отладчиком или логом с контекстом (`Debug.Log(message, this)`).
5. Исправь причину, а не симптом.
6. Проверь соседние сценарии и закрепи тестом, если это логика.

## Частые симптомы

| Симптом | Куда смотреть |
|---|---|
| `NullReferenceException` | Назначено ли поле; порядок инициализации |
| `MissingReferenceException` | Обращение к уничтоженному объекту |
| Триггер молчит | Коллайдеры, Rigidbody, Is Trigger, матрица слоёв |
| Кнопка не работает | EventSystem, перекрытие, Raycast Target |
| Персонаж дрожит | Движение transform у Rigidbody, Interpolate, порядок камеры |
| Значение не меняется | Инспектор переопределил значение из кода |
| Фризы | GC Alloc в Profiler |
| В редакторе работает, в билде нет | Сцены в билде, stripping, `UNITY_EDITOR`, пути файлов |
| Персонаж прыгает в воздухе | Маска земли содержит его собственный слой |
