# Чек-лист код-ревью

## Ответственность
- [ ] Класс имеет одну причину для изменения
- [ ] Логика правил отделена от визуала
- [ ] Метод делает одну вещь и помещается на экран

## Unity
- [ ] Поля закрыты, для инспектора используется `[SerializeField]`
- [ ] Ссылки кэшируются в `Awake`
- [ ] Подписки парные: `OnEnable` и `OnDisable`
- [ ] Физика работает в `FixedUpdate`, камера в `LateUpdate`
- [ ] Движение умножено на нужное время
- [ ] Не используется `?.` на объектах Unity
- [ ] Нет `Find` в рабочем цикле

## Производительность
- [ ] В частом коде нет `new`, LINQ, склейки строк
- [ ] Используются пулы для частых объектов
- [ ] Рейкасты ограничены `LayerMask`

## Надёжность
- [ ] Нет пустых `catch`
- [ ] Ошибки конфигурации видны сразу
- [ ] Проверены пауза, смерть, выключение объекта и смена сцены

## Читаемость
- [ ] Имена описывают смысл
- [ ] Магические числа вынесены в настройки или константы
- [ ] Комментарии объясняют причину, а не пересказывают код
