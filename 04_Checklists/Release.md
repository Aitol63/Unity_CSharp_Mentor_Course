# Чек-лист релиза

## Перед сборкой
- [ ] Все сцены добавлены в список сборки
- [ ] Заполнены название, версия, иконка
- [ ] Текстуры и звук сжаты под платформу
- [ ] Нет отладочных меню и лишних логов

## Проверка
- [ ] Чистая установка
- [ ] Обновление со старым сохранением
- [ ] Самое слабое целевое устройство
- [ ] Разные разрешения и соотношения сторон
- [ ] Сворачивание и потеря фокуса
- [ ] Новый игрок проходит игру без подсказок

## Публикация
- [ ] Страница, скриншоты, описание
- [ ] Лицензии на ассеты, шрифты и музыку проверены
- [ ] Есть способ собирать ошибки игроков
