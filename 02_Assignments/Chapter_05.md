# Глава 5. Ядро Unity

**Лекция:** глава 5 в `01_Lectures`.  
**Эталонный код:** `03_Practice/MentorCourse/` (02_Movement, 06_Spawn).

> Сначала сделай задание сам. Эталон открывай только после проверки по критериям.

## Задание 5.1. Лог жизненного цикла

**Уровень:** База

Добавь логи во все методы цикла, затем включай и выключай объект и скрипт. Зарисуй порядок вызовов.

**Готово, когда:**

- [ ] Ты можешь предсказать порядок для двух объектов сцены
- [ ] Объяснено, почему `Awake` вызывается у выключенного скрипта

## Задание 5.2. Настраиваемый компонент

**Уровень:** База

Сделай компонент вращения с `[SerializeField]`, `[Range]`, `[Header]` и `[Tooltip]`.

**Готово, когда:**

- [ ] Нет `public` полей ради инспектора
- [ ] Значения проверяются в `OnValidate`

## Задание 5.3. Система префабов

**Уровень:** Средний

Создай врага, Prefab Variant `Elite` и вложенный префаб оружия. Покажи работу Override.

**Готово, когда:**

- [ ] Изменение базы попадает в вариант
- [ ] Ты умеешь применить и откатить Override

## Задание 5.4. Переименование без потерь

**Уровень:** Средний

Переименуй сериализуемое поле, не потеряв значения в префабах.

**Готово, когда:**

- [ ] Используется `FormerlySerializedAs`
- [ ] Значение в инспекторе сохранилось

## Задание 5.5. Порядок инициализации

**Уровень:** Сложный

Сломай сцену намеренно: `A.Awake` читает данные `B`, которые готовы только в `B.Awake`. Исправь тремя способами и выбери лучший.

**Готово, когда:**

- [ ] Показаны `Start`, `DefaultExecutionOrder` и явный `Init`
- [ ] Записана причина выбора
