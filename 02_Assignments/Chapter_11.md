# Глава 11. Анимация, звук, эффекты

**Лекция:** глава 11 в `01_Lectures`.  
**Эталонный код:** `03_Practice/MentorCourse/` (09_AnimationAudio).

> Сначала сделай задание сам. Эталон открывай только после проверки по критериям.

## Задание 11.1. Персонаж с анимациями

**Уровень:** База

Импортируй модель и анимации (например с Mixamo), настрой Idle, Run и Attack.

**Готово, когда:**

- [ ] Анимация атаки запускается без задержки
- [ ] Параметры используются через хэши

## Задание 11.2. Звуковая группа

**Уровень:** База

Настрой Audio Mixer с группами Music, SFX, UI и слайдерами.

**Готово, когда:**

- [ ] Слайдер работает по логарифмической шкале
- [ ] Значения сохраняются

## Задание 11.3. Удар по кадру

**Уровень:** Средний

Нанеси урон через Animation Event и защити логику от прерывания анимации.

**Готово, когда:**

- [ ] Урон приходит точно в кадр удара
- [ ] Прерывание атаки не ломает состояние

## Задание 11.4. Blend Tree

**Уровень:** Средний

Сделай 2D Blend Tree для стрейфа.

**Готово, когда:**

- [ ] Переходы плавные
- [ ] Параметры вычислены в локальных координатах

## Задание 11.5. Сочный удар

**Уровень:** Сложный

Собери hit stop, тряску, частицы, звук и отброс в один удар.

**Готово, когда:**

- [ ] Эффекты подключены через события
- [ ] Удаление эффекта не ломает бой
