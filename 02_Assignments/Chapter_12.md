# Глава 12. Игровой ИИ

**Лекция:** глава 12 в `01_Lectures`.  
**Эталонный код:** `03_Practice/MentorCourse/` (07_AI).

> Сначала сделай задание сам. Эталон открывай только после проверки по критериям.

## Задание 12.1. Патруль

**Уровень:** База

Настрой NavMesh и обход контрольных точек.

**Готово, когда:**

- [ ] Агент не застревает на точках
- [ ] Пути обновляются не каждый кадр

## Задание 12.2. Зрение

**Уровень:** База

Покажи в Gizmos конус зрения и проверку препятствий.

**Готово, когда:**

- [ ] Стена блокирует обзор

## Задание 12.3. Полный автомат

**Уровень:** Средний

Собери врага с состояниями Patrol, Chase, Attack, Search.

**Готово, когда:**

- [ ] Каждое состояние в своём классе
- [ ] Враг ищет игрока в последней известной точке

## Задание 12.4. Боевая группа

**Уровень:** Средний

Сделай группу врагов с токенами атаки: одновременно бьют не больше двух.

**Готово, когда:**

- [ ] Остальные держат дистанцию

## Задание 12.5. Босс на Behaviour Tree

**Уровень:** Сложный

Реализуй босса с тремя фазами на `BtSelector`/`BtSequence`.

**Готово, когда:**

- [ ] Фазы переключаются по здоровью
- [ ] Дерево собирается в одном месте
