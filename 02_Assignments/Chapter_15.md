# Глава 15. Качество, производительность, релиз

**Лекция:** глава 15 в `01_Lectures`.  
**Эталонный код:** `03_Practice/MentorCourse/` (13_Performance, 14_Tests).

> Сначала сделай задание сам. Эталон открывай только после проверки по критериям.

## Задание 15.1. Первый замер

**Уровень:** База

Сними профиль билда и запиши три самых дорогих метода.

**Готово, когда:**

- [ ] Используется Development Build
- [ ] Замер не из редактора

## Задание 15.2. Тесты логики

**Уровень:** База

Напиши 10 тестов для кошелька, инвентаря и урона.

**Готово, когда:**

- [ ] Тесты независимы
- [ ] Названия описывают поведение

## Задание 15.3. Тысяча врагов

**Уровень:** Средний

Сцена с 1000 объектов: замени отдельные `Update` на `TickManager`.

**Готово, когда:**

- [ ] Есть замеры до и после
- [ ] Частые операции не создают мусор

## Задание 15.4. Разбор кадра

**Уровень:** Средний

Через Frame Debugger уменьши количество draw calls в сцене минимум на 30%.

**Готово, когда:**

- [ ] Записаны применённые приёмы
- [ ] Качество картинки заметно не упало

## Задание 15.5. Релиз

**Уровень:** Сложный

Опубликуй маленькую игру на itch.io.

**Готово, когда:**

- [ ] Пройден чек-лист релиза из `04_Checklists`
- [ ] Игрок без твоих подсказок доходит до конца
