## Задание 6.1. Турель

**Уровень:** База

Сделай турель, которая плавно поворачивается к цели только вокруг оси Y.

**Готово, когда:**

- [ ] Угол поворота в секунду задаётся в инспекторе
- [ ] Скорость не зависит от FPS

**Подсказка:** `Quaternion.RotateTowards`.

## Задание 6.2. Конус зрения

**Уровень:** База

Покажи в Gizmos, находится ли цель в конусе перед объектом.

**Готово, когда:**

- [ ] Цвет меняется при входе
- [ ] Используется `Vector3.Dot`

## Задание 6.3. Удар в спину

**Уровень:** Средний

Удар наносит тройной урон, если атакующий стоит сзади цели.

**Готово, когда:**

- [ ] Проверка работает при любом повороте
- [ ] Порог вынесен в настройки

## Задание 6.4. Снаряд с прицелом

**Уровень:** Средний

Рассчитай упреждение: снаряд летит туда, где цель окажется.

**Готово, когда:**

- [ ] Попадает в цель с постоянной скоростью
- [ ] Есть защита от неразрешимого случая

**Подсказка:** Начни с приближения: время = расстояние / скорость.

## Задание 6.5. Сплайн-траектория

**Уровень:** Сложный

Реализуй кривую Безье по трём точкам и проведи объект с постоянной скоростью.

**Готово, когда:**

- [ ] Кривая видна в Gizmos
- [ ] Скорость примерно постоянна
