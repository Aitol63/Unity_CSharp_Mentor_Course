# Глава 3. Память и система типов

**Лекция:** глава 3 в `01_Lectures`.  
**Эталонный код:** `03_Practice/MentorCourse/` (01_CSharpBasics, 13_Performance).

> Сначала сделай задание сам. Эталон открывай только после проверки по критериям.

## Задание 3.1. Угадай результат

**Уровень:** База

Напиши 6 маленьких примеров с `int`, `struct`, `class`, `List` и передачей в метод. Сначала запиши ожидаемый вывод на бумаге, затем проверь.

**Готово, когда:**

- [ ] Есть примеры с копией struct и общей ссылкой class
- [ ] Каждое расхождение объяснено комментарием

## Задание 3.2. Метод Swap

**Уровень:** База

Реализуй `Swap<T>(ref T a, ref T b)` и объясни, почему без `ref` он не работает.

**Готово, когда:**

- [ ] Работает для `int`, `string` и `Vector3`

## Задание 3.3. Найди аллокации

**Уровень:** Средний

Создай скрипт с `new List` в `Update`, склейкой строк и LINQ. Открой Profiler, запиши значения GC Alloc, затем избавься от них.

**Готово, когда:**

- [ ] Есть замеры до и после
- [ ] GC Alloc этого скрипта равен 0 в обычном кадре

**Подсказка:** Сними галочку Collapse и включи Deep Profile только для поиска источника.

## Задание 3.4. Безопасный null

**Уровень:** Средний

Воспроизведи проблему: вызови `?.` на уничтоженном объекте и получи `MissingReferenceException`. Исправь код.

**Готово, когда:**

- [ ] Ошибка воспроизводится стабильно
- [ ] В исправленной версии используется проверка Unity

## Задание 3.5. Утечка через событие

**Уровень:** Сложный

Создай статическое событие и подписчика, забывающего отписаться. Перезагрузи сцену несколько раз и покажи вызовы на уничтоженных объектах.

**Готово, когда:**

- [ ] Проблема видна в логе
- [ ] Исправление использует пару `OnEnable`/`OnDisable`
