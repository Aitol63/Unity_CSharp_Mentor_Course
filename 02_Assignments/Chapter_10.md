# Глава 10. Пользовательский интерфейс

**Лекция:** глава 10 в `01_Lectures`.  
**Эталонный код:** `03_Practice/MentorCourse/` (08_UI).

> Сначала сделай задание сам. Эталон открывай только после проверки по критериям.

## Задание 10.1. HUD

**Уровень:** База

Собери HUD со здоровьем и счётом для разрешений 16:9, 21:9 и 4:3.

**Готово, когда:**

- [ ] Элементы привязаны якорями
- [ ] Используется Canvas Scaler

## Задание 10.2. Главное меню

**Уровень:** База

Сделай меню, настройки и подтверждение выхода через `ScreenStack`.

**Готово, когда:**

- [ ] Кнопка «назад» работает на любой глубине

## Задание 10.3. MVP инвентаря

**Уровень:** Средний

Покажи инвентарь из главы 4 через модель, вид и презентер.

**Готово, когда:**

- [ ] Модель не содержит `using UnityEngine.UI`
- [ ] Подписки снимаются

## Задание 10.4. Плавающий урон

**Уровень:** Средний

Покажи всплывающие числа урона через пул.

**Готово, когда:**

- [ ] Нет `Instantiate` при каждом ударе
- [ ] Текст уходит вверх и исчезает

## Задание 10.5. Виртуальный список

**Уровень:** Сложный

Сделай прокрутку 10 000 элементов.

**Готово, когда:**

- [ ] Создаётся только видимое количество ячеек
- [ ] Прокрутка плавная
