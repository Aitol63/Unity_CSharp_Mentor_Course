# Глава 1. Фундамент C# и среды

**Лекция:** глава 1 в `01_Lectures`.  
**Эталонный код:** `03_Practice/MentorCourse/` (01_CSharpBasics).

> Сначала сделай задание сам. Эталон открывай только после проверки по критериям.

## Задание 1.1. Проект и Git

**Уровень:** База

Создай проект Unity 6, структуру `Assets/_Project/{Scripts,Prefabs,Scenes,Art,Audio,Configs}`, инициализируй Git и добавь `.gitignore` из `05_Templates`.

**Готово, когда:**

- [ ] `Library` и `Temp` не попали в коммит
- [ ] Asset Serialization стоит в Force Text
- [ ] Первый коммит содержит `.meta`-файлы

**Подсказка:** Перемещай файлы только внутри окна Project.

## Задание 1.2. Калькулятор урона

**Уровень:** База

Напиши статический класс `DamageMath` с методом `int Calculate(int baseDamage, float multiplier, bool isCritical)`. Крит удваивает итог.

**Готово, когда:**

- [ ] Результат не бывает отрицательным
- [ ] Округление задано явно через `Mathf.RoundToInt`
- [ ] Метод проверен минимум на 5 наборах чисел через `Debug.Log`

**Подсказка:** Проверь, что 5 / 2 и 5 / 2f дают разный результат, и объясни почему.

## Задание 1.3. Таблица уровней

**Уровень:** База

Выведи в Console таблицу: уровень от 1 до 20 и опыт для него по формуле `100 * level * level`. Затем найди первый уровень, где нужно больше 10 000 опыта.

**Готово, когда:**

- [ ] Используется `for`
- [ ] Поиск останавливается через `break` или ранний `return`
- [ ] Числа вынесены в именованные константы

## Задание 1.4. Парсер команд

**Уровень:** Средний

Напиши метод `TryParseCommand(string input, out string name, out int value)` для строк вида `heal 25`.

**Готово, когда:**

- [ ] Некорректная строка возвращает `false` без исключений
- [ ] Работает с лишними пробелами
- [ ] Есть минимум 6 проверок, включая пустую строку

**Подсказка:** Посмотри `string.Split` и `int.TryParse`.

## Задание 1.5. Сборка без редактора

**Уровень:** Сложный

Настрой проект так, чтобы код из папки `Editor` не попадал в билд, и собери билд под свою платформу.

**Готово, когда:**

- [ ] Билд запускается отдельно от редактора
- [ ] `using UnityEditor` не ломает сборку
- [ ] Ты можешь объяснить разницу Mono и IL2CPP своими словами
