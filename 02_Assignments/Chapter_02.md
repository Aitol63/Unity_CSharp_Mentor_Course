## Задание 2.1. Кошелёк с правилами

**Уровень:** База

Без подглядывания реализуй `Wallet`: золото нельзя изменить снаружи, трата возвращает `bool`.

**Готово, когда:**

- [ ] Поле золота не открыто для записи
- [ ] Отрицательная сумма обрабатывается
- [ ] Есть событие изменения

**Подсказка:** Сравни результат с `Wallet.cs` только после завершения.

## Задание 2.2. Иерархия врагов

**Уровень:** База

Создай абстрактный класс `Enemy` и наследников `Orc`, `Archer`, `Mage` с разной атакой.

**Готово, когда:**

- [ ] Метод атаки `abstract`
- [ ] Общий код только в базовом классе
- [ ] Вызов идёт через список `List<Enemy>`

## Задание 2.3. Интерфейс взаимодействия

**Уровень:** Средний

Создай `IInteractable` и реализуй его в двери, сундуке и рычаге. Игрок взаимодействует с ними одним кодом.

**Готово, когда:**

- [ ] Код игрока не содержит проверок конкретных типов
- [ ] Новый тип объекта добавляется без правки игрока

**Подсказка:** Эталон: `04_Physics/Interactor.cs`.

## Задание 2.4. Убери switch

**Уровень:** Средний

Перепиши код с `switch` по типу предмета (зелье, меч, свиток) на полиморфизм.

**Готово, когда:**

- [ ] `switch` исчез
- [ ] Новый предмет добавляется одним новым классом

## Задание 2.5. Композиция вместо дерева

**Уровень:** Сложный

Собери врага, бочку и ящик только из компонентов `Health`, `DestroyOnDeath`, `KnockbackReceiver` и одного нового `DropLoot`.

**Готово, когда:**

- [ ] Ни один компонент не знает о других типах объектов
- [ ] Разные объекты отличаются только набором компонентов

**Подсказка:** Подписывайся на `Health.Died`.
