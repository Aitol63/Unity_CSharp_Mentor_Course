# Глава 7. Ввод, движение и камера

**Лекция:** глава 7 в `01_Lectures`.  
**Эталонный код:** `03_Practice/MentorCourse/` (02_Movement, 03_Camera).

> Сначала сделай задание сам. Эталон открывай только после проверки по критериям.

## Задание 7.1. Персонаж без подсказок

**Уровень:** База

С нуля напиши движение на `CharacterController`: ходьба, гравитация, прыжок.

**Готово, когда:**

- [ ] Прыжок задаётся высотой в метрах
- [ ] Диагональ не быстрее прямого хода

## Задание 7.2. Камера-наблюдатель

**Уровень:** База

Сделай top-down камеру со сглаживанием.

**Готово, когда:**

- [ ] Обновление идёт в `LateUpdate`
- [ ] Нет дрожания персонажа

## Задание 7.3. Перенос на Input System

**Уровень:** Средний

Подключи `InputSystemReader` и назначь действия для клавиатуры и геймпада.

**Готово, когда:**

- [ ] Персонаж не менялся
- [ ] Работают оба устройства

## Задание 7.4. Game feel прыжка

**Уровень:** Средний

Добавь coyote time и jump buffer. Сравни ощущения с выключенными настройками.

**Готово, когда:**

- [ ] Значения настраиваются в инспекторе
- [ ] Можно прыгнуть сразу после схода с края

## Задание 7.5. Стена и рывок

**Уровень:** Сложный

Добавь прыжок от стены и рывок через состояния движения.

**Готово, когда:**

- [ ] Каждое состояние в отдельном классе
- [ ] Новая способность не требует правки других состояний
