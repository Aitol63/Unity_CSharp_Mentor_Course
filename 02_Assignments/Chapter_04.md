# Глава 4. Продвинутый C#

**Лекция:** глава 4 в `01_Lectures`.  
**Эталонный код:** `03_Practice/MentorCourse/` (01_CSharpBasics, 06_Spawn, 14_Tests).

> Сначала сделай задание сам. Эталон открывай только после проверки по критериям.

## Задание 4.1. Выбор коллекции

**Уровень:** База

Для пяти задач (инвентарь, поиск предмета по ID, очередь анимаций, история экранов, уникальные посещённые комнаты) выбери коллекцию и обоснуй в комментарии.

**Готово, когда:**

- [ ] Для каждой задачи указана сложность операции

## Задание 4.2. Инвентарь со стаками

**Уровень:** База

Реализуй инвентарь с вместимостью и стаками, затем сравни с `Inventory.cs`.

**Готово, когда:**

- [ ] Лишнее количество возвращается вызывающему
- [ ] Состояние нельзя изменить мимо методов

## Задание 4.3. Generic-реестр

**Уровень:** Средний

Напиши `Registry<TKey, TValue>` с `Add`, `TryGet`, `Remove` и событием добавления.

**Готово, когда:**

- [ ] Есть ограничение `where` там, где оно нужно
- [ ] Дубликат ключа обрабатывается явно

## Задание 4.4. Таблица лута

**Уровень:** Средний

Сделай таблицу лута с весами через `WeightedTable<T>`. Выполни 10 000 бросков и выведи распределение.

**Готово, когда:**

- [ ] Частоты близки к весам
- [ ] Генератор случайных чисел вынесен наружу для тестов

## Задание 4.5. Обработка ошибок

**Уровень:** Сложный

Напиши чтение конфигурации из JSON: нет файла, битый файл, неверная версия.

**Готово, когда:**

- [ ] В каждом случае понятное сообщение и значения по умолчанию
- [ ] Нет пустых `catch`
