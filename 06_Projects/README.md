# Проекты

Делай по порядку. Каждый проект доводи до играбельного билда.

| № | Проект | Навыки | Срок |
|---|---|---|---|
| 1 | Coin Rush | Движение, триггеры, UI, таймер | 3–5 дней |
| 2 | Arena Shooter | Оружие, пулы, ИИ, волны | 1–2 недели |
| 3 | Platformer | Game feel, камера, анимации | 1–2 недели |
| 4 | Mini RPG | Инвентарь, магазин, сохранения, MVP | 2–3 недели |
| 5 | Своя игра | Всё вместе и релиз | 3–6 недель |

## 1. Coin Rush

- [ ] Персонаж двигается и собирает монеты
- [ ] Таймер 60 секунд и счёт
- [ ] Экран победы, поражения и перезапуск
- [ ] Рекорд сохраняется
- [ ] Звук и эффект при сборе

## 2. Arena Shooter

- [ ] Камера сверху, прицел к курсору
- [ ] Два вида оружия
- [ ] Минимум 3 типа врагов и конфигурации волн
- [ ] Снаряды и эффекты в пуле
- [ ] HUD, пауза, экран итогов
- [ ] Нет заметных фризов при 100 врагах

## 3. Platformer

- [ ] Coyote time, jump buffer, разная гравитация
- [ ] 3 уровня с контрольными точками
- [ ] Движущиеся платформы и ловушки
- [ ] Анимации персонажа
- [ ] Hit stop, тряска, частицы

## 4. Mini RPG

- [ ] Инвентарь, экипировка, магазин
- [ ] Логика покрыта тестами
- [ ] Способности на ScriptableObject
- [ ] Сохранение с версией
- [ ] Минимум 2 сцены с загрузочным экраном

## 5. Своя игра

- [ ] Одна механика, которая интересна сама по себе
- [ ] Прототип за выходные
- [ ] Отзывы минимум от 5 человек
- [ ] Пройден `04_Checklists/Release.md`
- [ ] Публикация, например на itch.io

Главное правило: **уменьшай масштаб, а не сроки**. Маленькая законченная игра ценнее большой незаконченной.
