# Как внести вклад

Исправления опечаток, ошибок в коде и новые задания приветствуются.

## Правила для кода

- Скрипт должен компилироваться в Unity 6.
- Новая логика без сцены сопровождается тестом в `03_Practice/MentorCourse/14_Tests`.
- Класс `MonoBehaviour` или `ScriptableObject` лежит в файле с таким же именем.
- Приватные поля называются `_camelCase`, комментарии объясняют причину.
- Перед отправкой пройди `04_Checklists/Code_Review.md`.

## Проверка

Скопируй `03_Practice/MentorCourse` в проект и запусти **Window → General → Test Runner → EditMode → Run All**.

## Pull request

Один PR решает одну задачу. В описании укажи, что изменилось и как это проверено.
