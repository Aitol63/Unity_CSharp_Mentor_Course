# Физика

- `Interactor` + `Door`: `Origin` — камера, у двери назначь `Pivot`, на объекте двери нужен коллайдер.
- `TriggerZone`: коллайдер станет триггером при добавлении компонента.
- `Explosion`: в меню компонента есть команда **Explode**. Запусти её в Play Mode.
- `MovingPlatform`: создай пустые точки маршрута и назначь их в `Points`.
