# ИИ

1. Установи **AI Navigation**, добавь `NavMeshSurface` на пол и нажми **Bake**.
2. Создай врага с `EnemyBrain`. Нужные компоненты добавятся автоматически.
3. Настрой в `VisionSensor` поле `Eye` и слой препятствий. Слой персонажа в него не включай.
4. Назначь `Target` и точки патруля. Для ударов добавь `MeleeAttack`.

`BehaviourTree` и `UtilitySelector` не связаны с MonoBehaviour и показаны в тестах.
