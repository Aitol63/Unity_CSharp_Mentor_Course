# Интерфейс

- `HealthBarView`: Image типа **Filled** и объект с `Health`.
- `CounterMvp`, `CounterView`, `CounterInstaller`: полный MVP. Создай Canvas с текстом и кнопкой.
- `ScreenStack`: вызывай `Push` и `Pop` из кнопок.
- `CanvasFader`: работает и на паузе.
- `PauseMenu`: панель по умолчанию выключена.
- `SafeAreaFitter`: на панели, растянутой по экрану.
- `WorldBar`: держит элемент экранного Canvas над объектом.
