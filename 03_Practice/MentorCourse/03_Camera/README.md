# Камера

| Файл | Схема |
|---|---|
| `FollowCamera` | На камере; назначь цель |
| `FpsLook` | На камере, дочерней к персонажу; `Body` — корень персонажа |
| `OrbitCamera` | На камере; исключи слой персонажа из `Obstacle Mask` |
| `CameraShake` | На дочернем объекте, внутри которого лежит камера |

Вызывай `AddTrauma(0.4f)` при получении урона. Для продакшена изучи Cinemachine.
