# Производительность

- `TickManager`: один Update вместо сотен, с маркером для Profiler.
- `StaggeredTick`: распределение работы по кадрам.
- `ScoreTextNoAlloc`: обновление текста без мусора.
- `ColorTint`: изменение цвета без копии материала. Для URP Lit используется `_BaseColor`; в других шейдерах имя может отличаться.

Сначала измерь, потом оптимизируй.
