# Спавн

- `CoinSpawner`: быстрый пример таймера и пула.
- `WaveSpawner`: создай ассеты через **Create → Mentor Course → Wave**, назначь волны и точки появления. Префаб врага должен содержать `Health` и удаляться после смерти.
- `WeightedTable`: случайный выбор с весами, покрыт тестом.
