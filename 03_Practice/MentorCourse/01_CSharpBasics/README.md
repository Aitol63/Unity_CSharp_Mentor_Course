# Основы C#

Обычные классы без сцены. Их поведение показано в `14_Tests`.

| Файл | Что показывает |
|---|---|
| `Wallet` | Инкапсуляция, события, паттерн Try |
| `Inventory` | Коллекции, стаки, безопасное удаление |
| `Cooldown` | Struct и работа со временем |
| `SimplePool` | Generics и делегаты |
| `GameObjectExtensions` | Методы расширения |
